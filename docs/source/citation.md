# Citation

If you use RamanPL_2D in your research, please cite it as research software.

## Preferred citation

A `CITATION.cff` file is provided in the repository root in [Citation File Format (CFF) 1.2.0](https://citation-file-format.github.io/). GitHub displays this automatically on the repository sidebar.

```text
Software: RamanPL_2D
Author:   Hao Yu
Version:  0.4.12
Repository: https://github.com/barry063/RamanPL_2D
```

## BibTeX (manual)

```bibtex
@software{yu_ramanpl2d,
  author    = {Hao Yu},
  title     = {RamanPL\_2D},
  version   = {0.4.12},
  url       = {https://github.com/barry063/RamanPL_2D},
}
```

Please update the version field to match the version you used.
